# Changelog

This changelog summarizes public release notes for TimeKeeper. Detailed release notes are stored under `docs/release-notes`.

## v0.1.9

- Main tab hamburger button opens the registered notification list.
- Added a dedicated upcoming reminders button between the hamburger button and the add button.

## v0.1.8

- Added real-time fuzzy search to the registered notification list.
- Search targets include title, message, group name, and time display.

## v0.1.7

- Added support for multiple notification time ranges per notification.
- Updated registered notification list, upcoming reminders, popup display, skip behavior, and scheduling logic for multiple time ranges.
- Added support for `24:00` as an end time.

## v0.1.6

- Notification popup title, time, and message can be selected and copied.
- Added popup actions to open the related notification and mute an individual notification.

## v0.1.5

- Fixed Eorzea Time notifications remaining after the end time in some cases.
